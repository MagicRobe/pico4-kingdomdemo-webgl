📜 项目简介

《PICO4 王国》是一款为 PICO XR 头显打造的沉浸式王国防守游戏。玩家化身王国守卫者，挥舞大剑近战挥砍、切换连弩远程射击（箭矢带重力弹道）、举盾牌格挡，抵御一波波来袭的骷髅与双斧骷髅大军，守住建筑目标直至胜利。

游戏以波次防守为核心，配合每局结算的天赋成长（元进度永久强化）、波间三选一奖励、背包消耗品与战斗结算面板。所有数值由 Excel 配表（Luban 管线）驱动，改数值不用动代码。

本页为 WebGL 演示版：去除 XR 硬件依赖，用鼠标 + 键盘模拟 VR 操作（点击锁定鼠标后，可像头显一样 360° 观察），在桌面浏览器直接体验核心玩法。

⚔️

双武器战斗

大剑近战挥砍，连弩远程射击——箭矢带重力弹道，命中敌人才消耗耐久，Shift 一键切换。

🛡️

盾牌格挡

鼠标右键举盾格挡伤害，盾牌拥有独立耐久，可切换多面盾牌，硬抗一波强敌。

🧟

波次防守

骷髅、双斧骷髅等敌人一波波来袭，数量与强度持续递增。守住建筑目标，清场进入下一波，撑到最终胜利。

⭐

天赋成长

每局胜利结算天赋点，永久强化生命、攻击、防御、装备耐久——每一局都让角色更强（元进度）。

🎒

背包与道具

收集治疗药水等消耗品，随时使用；波间三选一奖励，组合出你的 build。

📜

结算面板

胜利/失败都有得分明细（波次×5 + 杀敌×1 + 建筑×5），天赋点立即到账；配合死亡重开、波次清场奖励，一局节奏完整。

⚙️ 技术要点
分层架构 · 事件驱动 · 配表管线 · 三端输入 · 测试覆盖
🏗️

分层架构

纯 C# 规则层（Core：扣血/死亡/数值 clamp）+ 引擎层解耦，规则可脱离 Unity 独立跑测试。

⚡

事件驱动

泛型 EventBus<T> 事件总线 + ServiceLocator 服务定位，模块通过事件与服务通信，减少直接依赖。

📊

配表驱动

Luban 管线：Excel → 强类型 C# + JSON，武器/敌人/盾牌/奖励等 14 张表，改数值不改代码。

🎮

三端输入

统一 IInputProvider 接口：PICO 手柄 / WASD+鼠标 / 触屏摇杆，一套逻辑跑三端。

🧪

测试覆盖

EditMode + PlayMode + 独立 dotnet 测试，数值规则（扣血/死亡/经验）有测试覆盖。

🗂️

工程化工具

对象池、音频事件驱动、波间奖励、存档元进度，配套 Editor 工具（配表导出/字体/贴图优化）。

🎯 规则层纯 C# 可测

战斗数值（扣血、死亡判定、经验升级）放在 Core/，零 Unity 依赖，用 tests-core/ 独立 dotnet 测试锁定行为。

⚡ EventBus + ServiceLocator

泛型 EventBus<T> 用 struct 事件零 GC 通信，ServiceLocator O(1) 注册查找，模块互不硬引用。

📊 Luban 配表管线

Excel 配表 → 一键导出强类型 C# + JSON，武器攻击力、敌人血量、升级经验全配表驱动。

🏗️ 初始化四段流水线

Init → Diagnose → Validate → Activate 四段式启动：模块逐个初始化（失败只记日志继续），诊断器收集结果，硬门校验，通过才启动游戏运行态——时序由结构保证。

🗃️ 对象池 + 生命周期

敌人走对象池复用，避免反复 Instantiate 重组件；MonoBehaviourService 基类代管 ServiceLocator 注册/注销，切场景自动清池，不累积驻留。

🎮 三端输入统一

IInputProvider 抽象 PICO 手柄 / WASD+鼠标 / 触屏摇杆，战斗逻辑只面向接口；无真机自动回退 Fallback，WebGL 天然可用。

战斗系统

大剑近战挥砍、连弩远程射击（箭矢带重力弹道），命中敌人才消耗耐久、空挥不扣；盾牌举盾格挡，耐久独立。Shift 切换武器、Ctrl 切换盾牌，一套输入三端通用。

波间奖励

🏆

结算与成长

按「波次×5 + 杀敌×1 + 建筑×5」结算天赋点，胜利失败都有得分明细面板；天赋永久强化生命、攻击、防御、装备耐久——每一局都让角色更强。
